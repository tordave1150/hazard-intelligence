# TMD composite image acceptance

4 November 2026, Asia/Bangkok. Accept a **qualified display-only image product** from the [official TMD monitor](https://weather.tmd.go.th/composite/index_composite.html), separately from TMD CAP and numerical QPE. This narrows the unresolved candidates in the [1 November review](radar-source-review-2026-11-01.md); it does not accept the ASCII/NetCDF quantity or any nowcasting branch.

- The monitor describes PCAPPI at 2 km, Marshall–Palmer Z = 200 R^1.6 and estimated rain rate in mm/hour. Preserve original PNG colors. No pixel-to-value queries, accumulation, area totals or hazard thresholds are accepted.
- Adopt the monitor's image coordinates, in longitude/latitude, clockwise from northwest: (95,22.5), (108,22.5), (108,4), (95,4). This is provider placement, not independent geodetic certification. The rectangle is image extent, not a validated coverage mask.
- Parse each original frame-list timestamp and interpret UTC exactly as the source viewer does. Display ICT and source UTC. Never synthesize times by subtracting an assumed frame cadence. The source latest clock and latest list time must match.
- Capture at most 13 listed frames spanning at most three hours. Require increasing quarter-hour times, valid bounded RGBA PNGs, identical frame hashes on a second pass, and unchanged source manifest/clock before promotion. These checks reduce mixed generations; the provider does not supply an atomic snapshot token.
- Transparent pixels, no echo, radar outages, clutter and missing coverage are not distinguishable from the published PNG alone. Describe blank areas as unverified, never zero rain or safe conditions. Radar estimates can include non-rain echoes and are not ground-gauge measurements.
- [TMD's copyright notice](https://www.tmd.go.th/content/copyright) describes attributed noncommercial republication of website images/content. This project remains personal/noncommercial and displays TMD attribution and direct source/terms links. This is the basis for this limited display decision, not an unrestricted data licence or commercial entitlement. No automation quota or SLA is published in the reviewed pages; use a bounded scheduled collector, no browser-to-provider fan-out.
- Store immutable PNGs in the user-selected Vercel Blob store, metadata only in MongoDB. Keep active and previous generations and remove older objects within this dedicated product prefix. Do not store image bytes in MongoDB or commit captured provider images.
- Target collection every 15 minutes; GitHub scheduling is best-effort. Show observation age independently from retrieval age and scheduler drift. Initial application policy: latest frame up to 45 minutes FRESH, up to 90 minutes DELAYED, beyond that STALE; hide stale imagery and stop playback. These are application display limits, not a TMD guarantee. Old historical frame times remain visible during playback.

Required verification before release: fixed source corners and three control-point projection calculations, immutable image/hash checks, mixed-generation rejection, failure preserving last good metadata, public image delivery, browser frame/time agreement, playback and opacity, stale/missing-image behavior, mobile layout and independent source overlays. Record results and limitations in the dated release receipt.
