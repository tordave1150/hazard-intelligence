# HII และ GISTDA: ขอบเขตทั้งประเทศไทย

โครงการนี้ใช้ขอบเขตทั้งประเทศไทย จังหวัดและอำเภอเป็นตัวกรองทั่วไป ไม่มีจังหวัดนำร่องหรือรายการสถานีเฉพาะพื้นที่เป็นค่าเริ่มต้น ให้ยึด [ขอบเขตปัจจุบัน](current-scope.md) และ [คู่มือปฏิบัติการ](operations.md)

## GISTDA

ใช้ Secrets ฝั่งเซิร์ฟเวอร์ที่มีอยู่ ได้แก่ GISTDA_API_KEY, MONGODB_URI และ MONGODB_DB_NAME ไม่ต้องใส่กุญแจลงในหน้าเว็บหรือช่อง Run workflow

- งานเผยแพร่: Latest GISTDA Thailand 3-day flood product
- งานตรวจ: Inspect GISTDA Thailand Disaster Features
- งานตรวจมีเฉพาะ service กับ window ค่าเริ่มต้น 3days ไม่มีช่องระบุอำเภอ
- `python -m pipelines.gistda.run --publish` ใช้คำขอทั้งประเทศย้อนหลัง 3 วันเสมอ
- การเลือกจังหวัดหรืออำเภอในเว็บกรองผลจากชุดประเทศ ไม่เปลี่ยนขอบเขตต้นทาง

เวลาตอบ API ไม่ใช่เวลาถ่ายภาพ ผลว่างไม่ยืนยันว่าไม่มีน้ำท่วม ดู [ผลเผยแพร่](gistda-three-day-release-2026-10-29.md)

## HII / ThaiWater

ขอบเขตที่จะเชื่อมคือทุกสถานีในประเทศไทยจากคำตอบต้นทางแบบไม่กรองพื้นที่ ไม่จำกัดด้วยรายการสถานีตัวอย่าง

ตรวจคำตอบสาธารณะล่าสุดวันที่ 29 ตุลาคม เวลา 23:12 ICT ได้สถานีอัตโนมัติ 805 จุด โดย 802 จุดผูกกับจังหวัดไทยได้ 76 จังหวัด อีก 3 จุดต้นทางระบุเมียนมา ชุดนี้ยังไม่มีรายการอัตโนมัติของอำนาจเจริญ ไม่ถือว่าจังหวัดนั้นไม่มีภัย

ชั้นสถานี HII ยังไม่เปิดจริง ต้องตรวจเวลาและคุณภาพรายสถานีต่อ ข้อมูลรายเดือนย้อนหลังไม่ใช่ข้อมูลปัจจุบัน และรายการ manual ที่ไม่มีค่าระดับน้ำหรือพิกัดไม่ถูกนับเป็นจุดระดับน้ำบนแผนที่ ดู [ผลตรวจประเทศ](thaiwater-access-review-2026-10-29.md)
