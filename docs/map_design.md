# Unified map design

The operational route is `/`. Source registry and methodology are supporting routes, not separate operational dashboards.

- [Thailand context and dam symbols](map-context-dams-release-2026-11-01.md): owned non-selectable focus mask/outline below products; existing river classes styled by zoom; captured basemap place labels fade outside Thailand at low zoom. Canonical boundaries and data-layer colors are unchanged. RID uses individual original points with normal-storage rings and list/keyboard access for overlapping markers.

- The enabled observation layers have a flowing legend above the canvas, with expandable source dates/qualifications. Long notes wrap on mobile rather than stacking at fixed pixel offsets over the map. Forecast display scales remain separate.
- HII cluster labels count water-level and rain product records separately (`น้ำ` / `ฝน`). Co-located products do not become a single unique-station count. Cluster colors identify product type, not danger; source observation age remains unknown. Selecting a cluster zooms; selecting a station preserves the existing point/history flow.

- Administrative navigation: Thailand → six pinned upstream reg_royin regions → province → district; breadcrumbs and Back to Thailand preserve metric, layer opacity and 2D/3D selection. Search accepts English names, Thai names and canonical IDs.
- National map uses simplified province geometry and point forecasts. Selecting a national polygon first chooses its region; within a region it chooses a province. Province/district views lazily load only the selected province's district file. Raw boundaries remain in `data/boundaries/raw`.
- deck.gl GeoJsonLayer handles 2D fill, selection and tooltips. MapLibre native fill, line and fill-extrusion layers handle 3D so geometry participates in DEM terrain rendering instead of sinking below it. Camera changes combine area bounds and pitch in one operation to prevent competing transitions.
- MapLibre terrain uses Mapterhorn raster-dem tiles with 1.2× visual exaggeration. Basemap uses OpenFreeMap Positron, with automatic service attribution. A basemap loading failure falls back to a local background plus static polygons; WebGL loss is disclosed while area controls remain usable.
- Rainfall display breaks: 0, 1, 10, 25, 50+ mm/24h. Probability breaks: 0, 20, 40, 60, 80+ percent. These are display scales, not validated danger thresholds. Missing/stale values are neutral gray.
- Local extrusion: rainfall ×150 display meters or probability ×50 display meters. The legend and controls explain that height has no flood-depth meaning. Extrusion requires local view, selected weather layer and a non-stale metric.
- The time dock owns Today and the next three Bangkok calendar dates, including explicit unavailable dates. Today returns to Situation; a future date selects daily forecast. Today's hourly forecast and observed radar are explicit backgrounds available on Today only. Radar frame selection and hourly intervals live in the same dock; the forecast values chart is not another date selector. GISTDA windows are independent retrospective source queries. Every weather panel preserves validity, requested/returned grid coordinates and retrieval time; model issue time remains unavailable.
- The [desktop workspace increment](desktop-workspace-release-2026-11-06.md) replaces the tall opening dashboard with a compact top bar, context strip, active source badges, collapsible rail controls, a stable map canvas and one contextual inspector. Overview and the existing 77-province comparison are on-demand dialogs. Closing/changing the inspector does not clear enabled overlays. Container ResizeObserver resizes the existing canvas without changing the camera fit algorithm.
- Desktop layout uses the available viewport height with independently scrolling panes. At ≤900px, the existing overlay-drawer approach remains; further mobile/fit refinement and device GPU/memory benchmarking are deferred. Dialogs support Escape, focus trapping and focus restoration. Reduced-motion styles are scoped to the workspace.

HII water/rain points, RID reports, TMD CAP, qualified radar images and GISTDA retrospective products are connected within their accepted source coverage. The separate 22-basin context uses DDPM geometry and conservative station/dam point matching; it does not infer basin rainfall totals or upstream/downstream connectivity. Numerical QPE, nowcasting and representative dam photos retain separate acceptance gates. Missing/empty data never implies safety.
