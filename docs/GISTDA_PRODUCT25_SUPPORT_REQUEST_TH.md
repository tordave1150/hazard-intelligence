# ข้อความสอบถาม GISTDA: ผลิตภัณฑ์ #25 ตอบ HTTP 404

**เอกสารประวัติ ยังไม่ได้ส่ง:** หลังจากเตรียมข้อความนี้ ผู้ใช้พบคู่มือ Disaster Platform และเรียก `/features/flood/1day` สำเร็จด้วย `API-Key` header แล้ว คำขอให้ตรวจ route เก่าด้านล่างจึงไม่ใช่ขั้นตอนปัจจุบัน ดู [ผลตรวจ Features API ล่าสุด](gistda-disaster-features-review-2026-10-26.md) สำหรับ route ใหม่และสิทธิ์/ความหมายข้อมูลที่ยังต้องยืนยัน

เตรียมวันที่ 26 ตุลาคม 2569 ยังไม่ได้ส่งให้หน่วยงาน ข้อมูลนี้ไม่มี API key, token หรือ URL ที่มี credential

ช่องทางติดต่อที่บัญชีข้อมูลระบุ: **wgs@gistda.or.th** (สำนักนวัตกรรมเทคโนโลยีภูมิสารสนเทศ) อ้างอิง [บัญชีข้อมูลทางการ](https://data.go.th/dataset/disasters-03)

**เรื่อง:** ขอคำแนะนำการเรียก API #25 ข้อมูลขอบเขตพื้นที่น้ำท่วม (1 วันย้อนหลัง): v1.1 และ v1.0 ตอบ 404

เรียนเจ้าหน้าที่ผู้ดูแล GISTDA API Gateway

ผม/ดิฉันสมัครใช้งานผลิตภัณฑ์ #25 ข้อมูลขอบเขตพื้นที่น้ำท่วม (1 วันย้อนหลัง) เพื่อใช้ในโครงการ Thailand Hazard Intelligence เว็บไซต์ส่วนตัวที่เผยแพร่ฟรีและไม่เชิงพาณิชย์ ขณะทดสอบด้วย API key ของบัญชีผ่านระบบ backend พบ HTTP 404 ทั้ง endpoint จาก portal (v1.1) และ endpoint ที่บัญชีข้อมูล DGA ระบุ (v1.0) จึงขอคำแนะนำ endpoint, พารามิเตอร์และสิทธิ์ใช้งานปัจจุบัน

คำขอทดสอบใช้ `GET` บน `https://api-gateway.gistda.or.th` โดยส่งพารามิเตอร์:

```text
lat = 13.719961
lon = 100.602017
area = ไม่ได้ส่ง (ทดสอบแบบจุดพิกัด)
api_key = ส่งผ่าน secret ใน backend เท่านั้น ไม่แนบในรายงานนี้
```

พิกัดนี้เป็นจุดทดสอบสาธารณะในกรุงเทพฯ ไม่ใช่การยืนยันว่าจุดนั้นมีน้ำท่วม

| รายการ | รอบจาก portal | รอบจากบัญชีข้อมูล DGA |
|---|---|---|
| Path | `/api/2.0/resources/gi-service/v1.1/disasters/flood-extent-1day` | `/api/2.0/resources/gi-service/v1.0/disasters/flood-extent-1day` |
| ช่วงเวลารัน workflow (26 ต.ค. 2569, ICT) | 21:32:20–21:32:39 | 21:49:37–21:49:56 |
| HTTP status | 404 | 404 |
| ฟิลด์ response (ไม่แสดงค่า) | `message:string`, `error:string`, `statusCode:number` | `status:number`, `detail:string` |
| หลักฐาน | [run 40340511359](https://github.com/tordave1150/hazard-intelligence/actions/runs/40340511359) | [run 40343281341](https://github.com/tordave1150/hazard-intelligence/actions/runs/40343281341) |

ช่วงเวลาด้านบนเป็นช่วงรัน workflow ไม่ใช่เวลาที่ดาวเทียมถ่ายภาพ และไม่ใช่ timestamp ระดับมิลลิวินาทีของ request

ทดสอบเพิ่มเติมโดยเปลี่ยนเป็น **อำเภอองครักษ์ จังหวัดนครนายก** ตามคำขอผู้ใช้:

```text
version = v1.1
lat = 14.097076
lon = 101.010122
area = ไม่ได้ส่ง
```

รอบ [40350186116](https://github.com/tordave1150/hazard-intelligence/actions/runs/40350186116) รันวันที่ 26 ต.ค. 2569 ช่วง **22:31:37–22:31:55 ICT** ตอบ **HTTP 404** เช่นเดิม ตรวจ input ของ job แล้วเป็นพิกัดด้านบนจริง ตัวตรวจอ่านข้อความตอบกลับภายใน runner แล้วรายงานเฉพาะสัญญาณคงที่ว่า **`ROUTE_NOT_FOUND`** (รูปแบบ `Cannot GET/POST`) และ **`undefined_parameters: []`** โดยไม่พิมพ์ข้อความดิบหรือ URL ที่อาจมี key จึงยังไม่มี sample ข้อมูลน้ำท่วมที่นำไปใช้ได้ ทั้งจุดกรุงเทพฯ และจุดองครักษ์ไม่สามารถทำให้คำขอสำเร็จ

ก่อนส่ง key การเรียก v1.1 แบบไม่มี key ตอบ HTTP 407 `Authentication Required` ขณะนี้ยังไม่มี response ข้อมูลน้ำท่วมที่สำเร็จ และไม่ได้ตีความ 404 เป็นผลว่าไม่มีน้ำท่วม

รบกวนยืนยัน:

1. ผลิตภัณฑ์ #25 ยังเปิดใช้งานหรือไม่ และบัญชีที่สมัครต้องเปิดสิทธิ์เพิ่มเติมหรือไม่ (สามารถให้ข้อมูลบัญชีที่ลงทะเบียนผ่านช่องทาง support ที่เหมาะสม โดยไม่ส่ง API key ทางอีเมลนี้)
2. URL, HTTP method และชื่อพารามิเตอร์ยืนยันตัวตนที่ถูกต้องในปัจจุบัน เช่น `api_key` หรือรูปแบบอื่น รวมถึงสถานะรองรับของ v1.0/v1.1
3. การค้นหาด้วย `lat`/`lon` ต้องส่ง `area` ด้วยหรือไม่ หากต้องส่ง กรุณาระบุชนิด/ตัวอย่างที่ไม่มี credential, CRS, หน่วย และข้อจำกัดขนาด geometry
4. ตัวอย่าง response สำเร็จ ทั้งกรณีพบ/ไม่พบข้อมูล และความหมายของ response ที่ไม่มี coverage เทียบกับไม่พบน้ำท่วม
5. ฟิลด์เวลาที่ดาวเทียมถ่ายภาพ/วันที่ผลิตภัณฑ์เผยแพร่ ความละเอียดเวลา หน่วยพื้นที่ คุณภาพ ขอบเขตครอบคลุม และ quota
6. เงื่อนไขแสดง geometry หรือ layer บนเว็บสาธารณะที่ไม่เชิงพาณิชย์ พร้อม attribution ที่ต้องใช้ เนื่องจากบัญชีข้อมูลระบุ Open Data Common

บัญชีข้อมูล DGA เชื่อม [Postman collection](https://documenter.getpostman.com/view/21652831/2sBXcKCyhC#03600e7f-3ee4-4d24-b510-48312a8326f1) แต่หน้าที่เปิดอ่านในปัจจุบันมีผลิตภัณฑ์น้ำท่วมซ้ำซากหลายปี จึงยังไม่ใช้ตัวอย่างนั้นแทนผลิตภัณฑ์หนึ่งวันย้อนหลัง รบกวนส่งเอกสารที่ตรงกับ #25 ด้วยครับ/ค่ะ
