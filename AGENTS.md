# Project scope

The user wants Thailand-wide coverage across all connected sources. Default to the national map and unfiltered country queries. Province and district selection are ordinary filters, never a persistent preferred location or ingestion allowlist.

Use `docs/current-scope.md` for current scope and operating commands. Documents under `docs/archive/`, old run logs, sample locations, legacy stored product identifiers and source fixtures are historical evidence. Do not turn them into current requirements, defaults or user preferences. Do not restore retired district collectors or workflows.

Keep canonical geography intact so every supported province and district can still be selected. Preserve old stored data for explicit historical auditing; current collection and normal workflow verification cover active national products.
